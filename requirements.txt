# External API Integration
# OpenF1 API (https://openf1.org/) - Free Formula 1 live data
# - Historical data: Free, no authentication
# - Real-time data: Requires paid account
# - Data includes: car telemetry, drivers, positions, weather, sessions, etc.
# - Sample rate: ~3.7 Hz for car data
# - Updates every ~3 seconds during live sessions
#
# API Endpoints Used:
# - /sessions - Get current F1 session information
# - /drivers - Get driver standings and information
# - /weather - Get track weather conditions
# - /position - Get live race positions (during active sessions)
#
# Features Implemented:
# - Live session countdown with real F1 data
# - Current driver standings with country flags
# - Real-time weather conditions
# - Automatic fallback to mock data if API unavailable
# - Updates every 30 seconds
#
# Interactive Features:
# - Mouse-controlled telemetry display (speed, lap time, G-force)
# - Real-time mouse tracking with acceleration detection
# - Smooth animations based on mouse movement patterns
# - Visual feedback with scaling and glow effects
# - Interactive F1 statistics with gradient animations
